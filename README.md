# 封面之间 · Cover Atelier

一个轻盈的公众号封面编辑工作台。左侧编辑，右侧实时预览；没有顶部书籍模板一览，也不需要反复上下滚动寻找画布。

## 运行

Node.js 22.12+ 或 24+：

```sh
npm ci
npm run dev
npm run typecheck
npm run build
```

默认预览端口 8443；`PORT=5173 npm run dev` 可以更改端口。

## 原版设计与创作流程

- **品牌恢复**：所有封面共用原版「爱豆书单 / IDOL BOOKLIST」星芒书页徽章。文案页可选曜石黑金、象牙朱砂、磨砂琉璃、赤金印章、青玉墨韵、赛博霓虹、铂金银白、落日琉光、紫糖贴纸；位置按原版锚点提供左上、右上、左下。风格切换不会重置品牌设置。
- **原版经典**：主题页选择「原版经典」，保留原版 12 种构图、8 套书籍意象、3 种立体书造型及 60 个复杂原版图腾。顶部书籍模板复用一览仍已移除，书籍选项收纳在侧栏。选择书籍仅更换视觉意象；点击「使用这本书的原版文案」才替换当前文字。
- **49 类风格**：轻盈浅色、宋韵东方、未来科技、独立杂志、文学书房、艺术海报，以及原版经典、奇幻史诗、历史人文、科普宇宙、心理成长、商业经管、悬疑推理、自然旅行、童书绘本、人物传记、哲学社科、诗词散文、图书典藏，并新增星云远航、AI 智能体、午夜插画、暗夜秘境、宇宙 Emoji、AI Emoji、阅读 Emoji 和赛博都市；进一步加入杂志特刊、复古印刷、文艺拼贴、抽象构成、国风剪纸、液态铬金、陶土浮雕、玻璃缎带。
- **自由混搭**：168 种构图、82 套配色、309 个背景选项（含原版背景、各分类的参数化纹理组合）和 240 个元素与插画（96 个新意象、60 个原版图腾、48 套可独立更换的主题插画、10 个 Emoji、12 个 3D 素材和 14 个山海阅读素材）。背景列表中的纸纹、网格、点阵、波纹与柔光按不同密度、位置和方向组合。
- **视觉层次**：提供清简线描、填色浮雕、光影辉光；新增星球、芯片、精装书、宫阙、心理之门、商业城市、侦探镜头、童话鱼、人物档案与古典柱廊等填色插画。可切换装帧增强，调节所选元素的浓度和大小。

## 分类与新增素材

主题库默认展示 8 个精选组合，可按书籍阅读、海洋水纹、山水自然、科幻宇宙、3D 材质、国风水墨、杂志文艺、插画趣味浏览。分类可交叉收录同一风格；「全部」展示完整主题库。搜索框在全库匹配主题名、描述、英文名与分类关键词。

新增浮光水纹、书页建筑、穹顶图书馆、深蓝大海、烟岚山水、水墨留白、湖面倒影、雪山之境、深空航行、星环宇宙、水晶涟漪、纸页峡谷、陶瓷海浪、宇宙之门 14 套主题，每套有 3 种构图，并提供对应的独立插画素材。

新增透明水晶球、悬浮书页、层叠石环、切面星球四种独立 3D 素材。素材库支持按 3D、水纹海洋、山水水墨雪山、图书图书馆、科幻太空、经典和 Emoji 筛选，仍可继续搜索及按画面位置浏览。

图层面板改为紧凑行，桌面将状态与操作放在同一行；手机端保留更易点击的分行操作。删除纯装饰的 WECHAT PREVIEW 等英文界面标题，保留封面本身可编辑的内容与品牌字样。

## 微信预览与可编辑角标

提供「单图文」「多图文叠题」「次条方图」三种模拟预览，推文标题可单独填写，不修改封面标题。多图文模式将标题叠在首图底部，并展示下方次条方图，便于检查遮挡与裁切。微信不同版本和展示入口会有差异，请以公众号后台预览及手机实际效果为准。模拟标题和遮罩不会进入 PNG。

右下角角标在文案页可编辑，默认 `IDOL BOOKLIST`，留空隐藏。现代封面不再自动显示左下角的英文风格分类。

设计参考与资料来源见 `DESIGN_REFERENCES.md`。

## 自由编辑主题图层

选择主题后，其默认插画会进入「当前主题与图层」列表，不再作为不可编辑的构图背景。每层都可隐藏/显示、删除、替换；同一位置可添加多个不同元素。新增图层会适当错位，点击「调整」可分别设置水平、垂直位置和大小。原版书籍的四组意象也会拆分为图层；原版立体书和内置构图图形提供独立开关及替换入口。

右侧原宣传卡片已改成当前主题与图层控制面板，支持收起/展开；显隐采用眼睛/划线眼睛图标、文字状态和不同底色区分，面板字号及操作区已放大；品牌、装帧和全部主题图形均可切换显示。左侧元素页也提供同一套控制。左右工作区使用统一的深色配色，已移除「回到原版经典」快捷入口，经典主题仍可在主题列表中选取。

左侧编辑文案、构图、主题与元素，右侧实时查看封面和微信消息卡片。长标题可自动适配现代构图；原版构图保留原先排版逻辑，可单独调整主副标题字号。主标题建议 8—20 字，长文案请自行检查换行与边缘。

所有编辑自动保存在当前浏览器，刷新后恢复；兼容已有 v2 草稿，不清理用户内容。支持撤销/重做（离开输入框后使用 ⌘/Ctrl+Z 和 Shift+⌘/Ctrl+Z）；重新开始也可撤销。历史记录不会跨刷新保留。

导出固定为 **2000 × 852 PNG**，不受屏幕大小影响。安全线和方图裁切辅助区域不会出现在导出图片中。消息卡片与主画布共用同一渲染器。

## 本地素材与限制

当前工作台的背景、图形和字体均不请求远程资源，使用系统中文字体；不同操作系统的字体及 Emoji 外观可能略有区别。草稿只保存在本机浏览器，不跨设备同步；清理浏览器数据会删除草稿。超长文案建议手动分行、精简副标题，以保持阅读效果。

## 文件

- `src/App.tsx`：工作台交互、自动保存与历史、导出。
- `src/CoverCanvas.tsx`：画布与卡片共享渲染、标题自适应。
- `src/Artwork.tsx`：新意象、Emoji、独立主题插画与原版缩略图。
- `src/WeChatPreview.tsx`：单图文、多图文叠题与次条方图模拟。
- `src/LandscapeArt.tsx`：水纹、藏书长廊、海浪、山水倒影、雪山与宇宙素材。
- `src/SculptureArt.tsx`：铬金、陶土凹凸、玻璃扭环等独立 3D SVG。
- `src/LayerPanel.tsx`：当前主题、图层显示、删除、替换与独立位置/大小控制。
- `src/BrandBadge.tsx`：原版品牌徽章、样式和位置。
- `src/ClassicScene.tsx`：原版 12 构图、书籍意象与图腾渲染。
- `src/classicOptions.ts`、`src/classicBackgrounds.ts`：原版素材目录。
- `src/RichScene.tsx`：新增分类插画、立体书与光影。
- `src/catalog.ts`：分类风格、构图、背景、元素和默认配置。
- `src/paletteLibrary.ts`：保留的原有配色定义。
- `src/index.css`：网页界面、分类封面风格、响应式布局。

原始 `公众号封面.zip` 为最初导入的备份，根目录源码为当前版本。
