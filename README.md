# 封面之间 · Cover Atelier

一个轻盈的公众号封面编辑工作台。左侧编辑，右侧实时预览；没有顶部书籍模板一览，也不需要反复上下滚动寻找画布。

## 运行

Node.js 22.12+ 或 24+：

```sh
npm ci
npm run dev
npm run typecheck
npm run build
```

默认预览端口 8443；`PORT=5173 npm run dev` 可以更改端口。

## 创作流程

1. **文案**：编辑主副标题、眉题、期号、署名及品牌。支持换行、宋体/黑体、字号和字距，长标题自动适配安全区域。
2. **构图**：30 种构图，包含轻盈浅色、宋韵东方、未来科技、独立杂志、文学书房、艺术海报六类。仅切换构图会保留文字、配色和元素。
3. **主题**：一键应用六类整套风格，也可自由混搭 40 套配色和 36 个本地背景选项。背景通过不同密度、方向和光影位置组合出纸感、网格、点阵、波纹和柔光效果。
4. **元素**：96 个原创 SVG 意象，主视觉、两侧、天空和前景各 24 个。每个位置可以选择 1 个，最多四层，支持搜索、移除、浓度和大小调整。

所有编辑自动保存在当前浏览器，刷新后恢复。支持撤销/重做（离开输入框后使用 ⌘/Ctrl+Z 和 Shift+⌘/Ctrl+Z）；重新开始也可撤销。历史记录不会跨刷新保留。

导出固定为 **2000 × 852 PNG**，不受屏幕大小影响。安全线和方图裁切辅助区域不会出现在导出图片中。下方消息卡片与主画布共用同一渲染器。

## 本地素材与限制

当前工作台的背景、图形和字体均不请求远程资源，使用系统中文字体；不同操作系统的字体外观可能略有区别。草稿只保存在本机浏览器，不跨设备同步；清理浏览器数据会删除草稿。超长文案建议手动分行、精简副标题，以保持阅读效果。

## 文件

- `src/App.tsx`：工作台交互、自动保存与历史、导出。
- `src/CoverCanvas.tsx`：画布与卡片共享渲染、标题自适应。
- `src/Artwork.tsx`：96 个 SVG 意象。
- `src/catalog.ts`：六类风格、构图、背景、元素和默认配置。
- `src/paletteLibrary.ts`：保留的原有配色定义。
- `src/index.css`：网页界面、六类封面风格、响应式布局。

原始 `公众号封面.zip` 为最初导入的备份，根目录源码为当前版本。
