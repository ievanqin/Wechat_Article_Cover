# Wechat Article Cover · 公众号封面工作台

基于 React 19、Vite 8、Tailwind CSS 4 的书单封面编辑器，支持 2.35:1 画布、文案与字号编辑、微信卡片预览和 2 倍 PNG 导出。

## 本地运行

需要 Node.js 22.12+（或 24+）。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认端口为 8443。可用 `PORT=5173 npm run dev` 调整端口。

```sh
npm run typecheck
npm run build
npm run preview
```

仓库根目录提供可直接运行的源码；原始 `公众号封面.zip` 保留作导入备份，不代表最新代码。

## 主题与元素

- 12 种版式，16 套配色，16 种背景（含跟随书籍背景）。
- 72 个可自由混搭的视觉元素：居中 19、两侧 18、天空 18、底部 17。
- 新增配色：茶白竹青、杏橘手记、雾紫来信、蔚蓝航线、荧光实验室、赤陶大地。
- 新增背景：留白纸间、深海航线、植物档案、数字实验室，均无需外部图片。
- 新增 SVG 元素：行星轨道、植物嫩芽、群山旭日、橄榄枝、旅行邮戳、电路节点、纸飞机、气泡、流星、城市天际线、梯田、沙丘露营。

在第四步输入元素名称或“自然”“旅行”“科技”等标签进行搜索，搜索会展开全部分类；再次点击已选元素可取消。

## 导出与限制

PNG 导出等待字体加载，自动排除安全区辅助线，并对失败显示可操作提示。导出文件名会过滤不兼容字符。

原有书籍背景使用远程图片，字体来自 Google Fonts，访问和导出效果受网络、跨域策略及本机字体影响。选择新增背景可以去除背景图请求；完全离线使用仍可能回退到系统字体。画布在不同视口下按当前宽度导出 2 倍图片，比例保持 2.35:1。

## 维护

- `src/App.tsx`：工作台、配色、背景、版式与原有元素。
- `src/ExtraElements.tsx`：新增元素目录及向量绘制，共用于所有版式的主画布与卡片预览。
- `src/index.css`：Tailwind 与字体入口。

当前编辑内容保存在页面内存中，刷新后会恢复默认值。
