# 封面之间 · Cover Atelier

一个轻盈的公众号封面编辑工作台。左侧编辑，右侧实时预览；没有顶部书籍模板一览，也不需要反复上下滚动寻找画布。

## 运行

Node.js 22.12+ 或 24+：

```sh
npm ci
npm run dev
npm run typecheck
npm run build
```

默认预览端口 8443；`PORT=5173 npm run dev` 可以更改端口。

## 原版设计与创作流程

- **品牌恢复**：所有封面共用原版「爱豆书单 / IDOL BOOKLIST」星芒书页徽章。文案页可选曜石黑金、象牙朱砂、磨砂琉璃；位置按原版锚点提供左上、右上、左下。风格切换不会重置品牌设置。
- **原版经典**：主题页选择「原版经典」，保留原版 12 种构图、8 套书籍意象、3 种立体书造型及 60 个复杂原版图腾。顶部书籍模板复用一览仍已移除，书籍选项收纳在侧栏。选择书籍仅更换视觉意象；点击「使用这本书的原版文案」才替换当前文字。
- **19 类风格**：轻盈浅色、宋韵东方、未来科技、独立杂志、文学书房、艺术海报，以及原版经典、奇幻史诗、历史人文、科普宇宙、心理成长、商业经管、悬疑推理、自然旅行、童书绘本、人物传记、哲学社科、诗词散文、图书典藏。
- **自由混搭**：78 种构图、52 套配色、129 个背景选项（含原版背景、各分类的参数化纹理组合）和 156 个元素（96 个新意象与 60 个原版图腾）。背景列表中的纸纹、网格、点阵、波纹与柔光按不同密度、位置和方向组合。
- **视觉层次**：提供清简线描、填色浮雕、光影辉光；新增星球、芯片、精装书、宫阙、心理之门、商业城市、侦探镜头、童话鱼、人物档案与古典柱廊等填色插画。可切换装帧增强，调节所选元素的浓度和大小。

左侧编辑文案、构图、主题与元素，右侧实时查看封面和微信消息卡片。长标题可自动适配现代构图；原版构图保留原先排版逻辑，可单独调整主副标题字号。主标题建议 8—20 字，长文案请自行检查换行与边缘。

所有编辑自动保存在当前浏览器，刷新后恢复；兼容已有 v2 草稿，不清理用户内容。支持撤销/重做（离开输入框后使用 ⌘/Ctrl+Z 和 Shift+⌘/Ctrl+Z）；重新开始也可撤销。历史记录不会跨刷新保留。

导出固定为 **2000 × 852 PNG**，不受屏幕大小影响。安全线和方图裁切辅助区域不会出现在导出图片中。消息卡片与主画布共用同一渲染器。

## 本地素材与限制

当前工作台的背景、图形和字体均不请求远程资源，使用系统中文字体；不同操作系统的字体外观可能略有区别。草稿只保存在本机浏览器，不跨设备同步；清理浏览器数据会删除草稿。超长文案建议手动分行、精简副标题，以保持阅读效果。

## 文件

- `src/App.tsx`：工作台交互、自动保存与历史、导出。
- `src/CoverCanvas.tsx`：画布与卡片共享渲染、标题自适应。
- `src/Artwork.tsx`：新意象、填色/光影模式与原版缩略图。
- `src/BrandBadge.tsx`：原版品牌徽章、样式和位置。
- `src/ClassicScene.tsx`：原版 12 构图、书籍意象与图腾渲染。
- `src/classicOptions.ts`、`src/classicBackgrounds.ts`：原版素材目录。
- `src/RichScene.tsx`：新增分类插画、立体书与光影。
- `src/catalog.ts`：分类风格、构图、背景、元素和默认配置。
- `src/paletteLibrary.ts`：保留的原有配色定义。
- `src/index.css`：网页界面、分类封面风格、响应式布局。

原始 `公众号封面.zip` 为最初导入的备份，根目录源码为当前版本。
